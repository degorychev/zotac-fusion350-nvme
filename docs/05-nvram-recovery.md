# Восстановление NVAR

Официальный образ содержал clean first bank со `StdDefaults` и полностью erased
second bank. Анализ не выявил в template данных, которые требовалось переносить
с конкретной машины. Для первого эксперимента live variables старого dump не
переносились вообще: firmware получила возможность создать их заново.

Проверенная операция заменяет только `0x000000–0x01FFFF`; диапазон
`0x020000–0x3FFFFF`, включая NVMe DXE, остаётся побайтно прежним. Builder также
проверяет, что второй официальный bank состоит только из `FF`, FV header валиден,
а итоговый SHA-256 совпадает с известным результатом.

Риски первого старта: сброс Setup preferences, новое обучение памяти, создание
runtime variables, изменение boot order и необходимость заново проверить SATA,
CSM, fan/temperature и clock settings. Прошивка не автоматизирована проектом.
